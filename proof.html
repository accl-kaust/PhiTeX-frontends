Method

        
How we measure.

      

      

        
Corpora
TeX Live's own documentation, the TRIP test, and a sample of arXiv sources, frozen by hash. The list is published with the results.

        
Machines
Named hardware, a quiet machine, the median of 11 runs after 3 warm-ups. Browser figures in Chromium, on the same wasm the extensions ship.

        
Keystroke → page
From the editor's transaction to the repainted page on screen, measured in the page, not in the core alone.

        
Reproducible
One command runs it all in a sandbox; the scripts and raw numbers are in the repository.
