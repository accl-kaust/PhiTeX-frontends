`latex.grammar` and `tokens.mjs`: Overleaf's LaTeX grammar for Lezer, from
overleaf/overleaf `services/web/frontend/js/features/source-editor/lezer-latex/`
(AGPL-3.0), unmodified. `tools/build/mock-editor.sh` generates the parser and
bundles `editor.mjs` into `tools/mock/build/editor.js`, which the mock page loads.
