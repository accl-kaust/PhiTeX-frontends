How it works

Your browser does the compiling.

The PhiTeX core runs as WebAssembly in the extension's offscreen document. It reads Overleaf's editor transactions as you type, collaborators' edits too, and repaints the preview. It never writes to Overleaf and never changes your documents.

All local

The PhiTeX core runs in your browser as WebAssembly, in the extension's offscreen document. There is no server of ours, and no code is loaded remotely.

Your editor, untouched

Your whole project

Every file, every package, every figure: PhiTeX builds the project exactly as Overleaf would, only as you type.

FAQ

Questions.

Is my document uploaded?

No. Everything runs locally, in your browser, as WebAssembly. The extension's only requests go to overleaf.com, as you, for your own project's files, the same way the editor gets them. It has no analytics, no server and no remote code.

Does it change my Overleaf project?

No. The extension only reads Overleaf's editor transactions to keep its own preview in sync. It never writes to Overleaf, so your documents and history are untouched.

Does it work with collaborators?

Yes. It follows the same editor transactions Overleaf applies, so a collaborator's edits repaint your instant preview too.

Is it the same engine as the CLI?

Yes, the same PhiTeX core, compiled to WebAssembly. The PDF is byte-identical to pdfTeX, and the instant result always equals a full rebuild. See the compiler →

Is it free and open source?
