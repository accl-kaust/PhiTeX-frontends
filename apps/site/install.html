Get One line, one binary.

Linux and macOS, on x86-64 and ARM.

curl -fsSL https://phitex.org/install.sh | sh

Or the nightly build:

curl -fsSL https://phitex.org/install.sh | PHITEX_CHANNEL=nightly sh

Windows 10 and 11, on x86-64 and ARM, with TeX Live for Windows. In PowerShell:

irm https://phitex.org/install.ps1 | iex

Or the nightly build:

$env:PHITEX_CHANNEL = "nightly"; irm https://phitex.org/install.ps1 | iex

Then, in your paper's folder:

phitex watch paper.tex

Your editor

Set it up where you write.

The same compiler and the same instant page in each. A project with several .tex files names its main one in phitex.toml: main = "paper.tex".

In Neovim, Emacs and other LSP editors, the diagnostics are TeX's errors, LaTeX's warnings (an undefined \ref or \cite, a font substituted) and every overfull and underfull box. The page's filter by kind reaches the editor soon.

Overleaf

Nothing to install: it runs in your browser

VS Code

VS Code 1.85+ · brings its own engine

PhiTeX ⚡ Instant (accl-kaust.phitex): a live page beside your editor, errors in the Problems panel, click-to-source both ways.

  1. Install it. The Marketplace and Open VSX listings are coming soon; until then, from a .vsix built from PhiTeX-frontends: 
    code --install-extension phitex-1.0.1.vsix
  2. Open a .tex file and run PhiTeX: Open Preview from the Command Palette.
  3. Optional: with phitex installed, PhiTeX: Switch Engine runs phitex watch instead of the built-in engine.

Neovim

Neovim 0.11+ · needs phitex nightly 202611041513+

phitex.lua: the buffer is built as you type, TeX's errors are diagnostics, and the page follows your cursor.

  1. Add it with your plugin manager. With vim-plug, in init.vim: 
    Plug 'accl-kaust/PhiTeX-frontends', { 'rtp': 'apps/editors/nvim' }
    With lazy.nvim: 
    { "accl-kaust/PhiTeX-frontends",
  config = function(p) dofile(p.dir .. "/apps/editors/nvim/phitex.lua") end }
    With no plugin manager, as a Neovim package: 
    git clone --depth 1 https://github.com/accl-kaust/PhiTeX-frontends ~/.local/share/phitex-frontends
mkdir -p ~/.local/share/nvim/site/pack/phitex/start
ln -s ~/.local/share/phitex-frontends/apps/editors/nvim ~/.local/share/nvim/site/pack/phitex/start/phitex
    Or just the one file, in your config: 
    curl -fsSLo ~/.config/nvim/plugin/phitex.lua \
  https://raw.githubusercontent.com/accl-kaust/PhiTeX-frontends/dev/apps/editors/nvim/phitex.lua
    Any other manager works the same way: add the repository with apps/editors/nvim on the runtimepath.
  2. Open a .tex file. <leader>lv opens the page; double-click it to jump back to the source.
  3. Optional, the build's state in your statusline: 
    vim.o.statusline = "%f %m%=%{v:lua.PhitexStatus()} "

In Vim, see Any LSP editor. Commands: :PhiTeXViewer, :PhiTeXRebuild, :PhiTeXSavePdf, :PhiTeXStop, :PhiTeXRestart. Settings in PhitexSettings, e.g. { threads = 4, follow = "selection" }. With no phitex on your PATH, it offers to download the latest release into ~/.local/bin (:PhiTeXInstall), checked against its minisign signature; it needs curl and minisign.

Emacs

Emacs 29+ · needs phitex nightly 202611041513+

phitex.el, a minor mode: it runs beside eglot or lsp-mode (or nothing), with diagnostics in flymake and the build's state in the mode line.

  1. Add it with use-package (Emacs 30's :vc; on 29, straight or elpaca the same way): 
    (use-package phitex
  :vc (:url "https://github.com/accl-kaust/PhiTeX-frontends"
       :lisp-dir "apps/editors/emacs" :rev :newest)
  :hook ((LaTeX-mode latex-mode) . phitex-mode)
  :custom (phitex-settings '(:follow "selection")))
    Or download it: 
    curl -fsSLo ~/.emacs.d/phitex.el \
  https://raw.githubusercontent.com/accl-kaust/PhiTeX-frontends/dev/apps/editors/emacs/phitex.el
    and turn it on in TeX buffers, in your init file: 
    (load "~/.emacs.d/phitex.el")
(add-hook 'LaTeX-mode-hook #'phitex-mode)   ; and/or latex-mode-hook
  2. M-x phitex-open-viewer opens the page.

With no phitex on your PATH, the mode offers to download the latest release into ~/.local/bin (M-x phitex-install), checked against its minisign signature; it needs curl and minisign.

Any LSP editor

Needs phitex

phitex watch --lsp is a language server: your buffers are built as you type, problems are published, and your cursor is shown on the page. Add it as a server for TeX files, beside any other. In Helix, for example (languages.toml):

[language-server.phitex]
command = "phitex"
args = ["watch", "--lsp"]

[[language]]
name = "latex"
language-servers = ["texlab", "phitex"]

In Vim, with vim-lsp (in your vimrc):

au User lsp_setup call lsp#register_server({
  \ 'name': 'phitex',
  \ 'cmd': {server_info->['phitex', 'watch', '--lsp']},
  \ 'allowlist': ['tex', 'plaintex'],
  \ })

A browser tab

Needs phitex

Beside any editor at all: the page lives in a tab and is rebuilt every time you save.

phitex watch paper.tex

It opens http://127.0.0.1 in your browser. Double-click the page to reach the source.

latexmk, scripts, CI

Needs phitex

One build does what latexmk does, BibTeX, biber and makeindex inside it.

phitex build paper.tex                 # the finished PDF, like latexmk -pdf
phitex --compat=pdflatex paper.tex     # one run, exactly as pdflatex

Under the name pdflatex, PhiTeX takes pdflatex's command line and makes one run, as pdflatex would.
