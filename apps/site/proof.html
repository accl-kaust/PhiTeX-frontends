The same PDF, measured.

PhiTeX builds each document, and so do pdfLaTeX and XeLaTeX. We compare the two PDFs byte for byte, publish every document that differs and why, and publish how long it takes.

Same PDF

Byte for byte, document by document.

Both PDFs are built from the same sources with the same TeX Live. They count as identical when the whole files match. Nothing is normalized after the build: both run with the same fixed date, time zone and locale, so equal input gives equal bytes.

Speed

Fast where you wait: after an edit.

PhiTeX rebuilds only what an edit changes, so the time that matters while writing is from a change to its new page. A clean build is shown as well, against pdfLaTeX and XeLaTeX on the same machine.
